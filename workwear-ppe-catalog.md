## 7. Safety Footwear (Chaussures et Bottes)

### 7.1 Safety Shoes (Chaussures de sécurité)
- Low-cut safety shoe / trainer style
- Safety sneaker (lightweight, sport-inspired)
- Derby / lace-up safety shoe
- Slip-on safety shoe / moccasin
- Safety sandal (S1 type)
- Chef / kitchen clog (slip-resistant)

### 7.2 Safety Boots (Bottes et brodequins de sécurité)
- Ankle safety boot (mid-cut)
- High-leg work boot (lace-up)
- Zip-side safety boot
- Wellington / rubber safety boot (botte en caoutchouc)
- PVC / nitrile safety boot (chemical, food industry)
- Insulated winter safety boot
- Chainsaw boot (cut-resistant)
- Welding / metatarsal boot (lace-free, fireproof)
- Firefighter / rescue boot
- Electrical insulating boot (dielectric)
- Waterproof membrane boot (Gore-Tex type)

### 7.3 Protection Features (shoe and boot)
- **Toe cap:** steel, composite, aluminum
- **Midsole:** steel plate, composite plate (anti-penetration)
- **Sole:** oil-resistant, slip-resistant, heat-resistant (HRO)
- **Other:** anti-static (ESD), shock absorption, waterproof (WRU)

### 7.4 Safety Classes (EN ISO 20345)
| Class | Main protection |
|---|---|
| **SB** | Basic protection (toe cap) |
| **S1** | SB + closed heel, anti-static, energy absorption |
| **S1P** | S1 + anti-penetration plate |
| **S2** | S1 + water resistance |
| **S3** | S2 + anti-penetration plate + cleated sole |
| **S4 / S5** | Rubber / PU boots (waterproof, S5 with plate) |

### 7.5 Footwear Accessories
- Work socks (thermal, anti-static, reinforced)
- Insoles (anti-fatigue, anti-penetration)
- Overshoes / shoe covers (disposable)
- Ice grips / anti-slip crampons

## 16. Fit and Silhouette Variations (applied to any garment above)

| Fit | Description |
|---|---|
| **Slim / fitted** | Close to the body, modern look, less fabric |
| **Regular / classic** | Standard cut, balanced room |
| **Relaxed / loose** | Extra room, easier layering |
| **Boxy** | Wide, straight, shorter body |
| **Tapered** | Narrows from knee to ankle |
| **Straight** | Consistent width through the leg |
| **Bootcut** | Slight flare to fit over boots |
| **Athletic** | More room in chest/thigh, tapered below |
| **Women's cut** | Shaped waist and bust, narrower shoulders and hips |
| **Unisex** | Neutral cut across sizes |
| **Plus / big and tall** | Extended sizing with adjusted proportions |

---

## 17. Key Construction Features

- **Closures:** zip, button, snap, hook-and-loop
- **Pocket configuration:** chest, hip, thigh, cargo, tool, phone, pen
- **Reinforcement:** knee, elbow, seat, shoulder patches
- **Ventilation:** underarm zips, mesh panels, back vents
- **Adjustability:** waist tabs, cuff straps, elasticated hem
- **Visibility:** reflective tape, fluorescent colors (Class 1/2/3)
- **Collar types:** shirt collar, mandarin, hooded, stand-up
- **Fabric technology:** cotton / poly blend, ripstop, canvas, stretch, FR-treated, anti-static, waterproof breathable
